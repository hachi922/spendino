給与額

資産のイメージ ⓘ元本は積み立てた額、運用益は評価額から元本を引いた額です。試算は、想定年利で月ごとに複利計算した見込みで、将来を保証するものではありません。銀行預金は試算せず、最新の記録の金額のまま合計に足します。

試算の設定 ⓘ元手は「開始月」の時点の金額です。積立は開始月の翌月から数えます。投資期間(開始月〜終了月)は手動で指定します。

Googleドライブで同期

記録は、いま使っているブラウザに自動で保存されます。Googleドライブと同期すると、スマホとPCで同じ記録を使えます。

初回の設定(クライアントID)
  1. Google Cloud Console で新しいプロジェクトを作ります。
  2. 「APIとサービス」→「ライブラリ」で Google Drive API を有効にします。
  3. OAuth同意画面(Google Auth Platform)を、対象「外部」で作り、テストユーザーに自分のGoogleアカウントを追加します。データアクセスに drive.appdata を追加します。
  4. 「認証情報」で「OAuthクライアントID」(ウェブアプリケーション)を作り、承認済みのJavaScript生成元に を入れます。
  5. できたクライアントIDを下の欄に貼って保存し、「同期する」を押します。

給料日と集計期間

毎月の給料日(土日・祝日のときは直前の平日に前倒し)から、次の給料日の前日までを「1か月分」として、固定費と記録をひもづけます。空欄にすると、1日〜月末の暦の月になります。祝日は、このアプリの中で計算しています(通信は不要です)。

月末払いは 31 と入れます。この設定は、この端末のブラウザに保存されます(同期はされません)。ほかの端末でも入れてください。
